# 诊断完整示例

> 用途：首次执行本技能、或对输出格式拿不准时，按本示例流程操作。示例为演示数据，非真实剧本。

## 1. 用户提供的剧本片段（示例）

> 集1（约3分钟）：
> 开场：苏晚在集团年会上被继母当众羞辱"野种也配站上台"。（受压）
> 紧接着苏晚不慌不忙亮出集团30%股权文件，董事会当场改口，继母脸色铁青。（即时反转）
> 散会后，苏晚收到匿名短信："你以为赢了吗？你母亲的死因在查下去你会后悔。"（新威胁）
> 苏晚在停车场偶遇男主陆沉，陆沉护着她躲过一辆失控货车，两人对视。（心动）
> 结尾画面：苏晚的办公室保险柜里，一份标注"已解密"的调查档案，镜头特写档案封面上的一个名字。（悬念钩子）

## 3. 脚本输入 JSON（对应示例）

```json
{
  "title": "示例短剧",
  "episodes": [
    {
      "no": 1,
      "length_min": 3.0,
      "events": [
        {"name": "被继母当众羞辱", "type": "neg1", "intensity": 4, "duration_min": 0.6},
        {"name": "亮股权文件当场打脸", "type": "zero", "intensity": 5, "duration_min": 0.7},
        {"name": "匿名威胁短信", "type": "neg1", "intensity": 3, "duration_min": 0.5},
        {"name": "陆沉英雄救美心动", "type": "pos1", "intensity": 3, "duration_min": 0.6},
        {"name": "调查档案特写悬念", "type": "neg1", "intensity": 2, "duration_min": 0.4}

}
```

运行：`python3 scripts/rhythm_metrics.py 上表.json`


## 5. 诊断报告（交付示例）

**覆盖范围**：集1 单集片段（约3分钟）。

**指标汇总**：爽点 1 个（密度 0.33/分，单集 3 分钟 1 个爽点达标）；正一 1 / 负一 3 / 零 1。

**情绪心电图**：

```
集1: -4 → 0(5) → -3 → +3 → -2   [1个爽点, 结尾负一钩子]
```

**问题清单**：

| 问题 | 证据 | 影响 |
|---|---|---|
| 爽点密度偏低 | 全片仅 1 个零；最长无爽点跨度 4 个情节点（≈1.8分钟） | 中段情绪有真空，可能流失 |
| 开局节奏偏慢 | 第 1 情节点为受辱铺垫，前 30 秒无反转 | 前 3 秒钩子弱 |
| 结尾钩子强度不足 | 档案特写强度仅 2，名字悬念无台词强化 | 追更动力一般 |

**优化建议**（原情节 → 改写建议）：

1. 爽点不足 → 把"匿名威胁短信"改为"苏晚反手把短信内容连同调查档案直接曝光给媒体，继母当众下不来台"，即在集 1 制造第二个零（负一危机+正一破局），预期爽点密度升至 0.67/分。
2. 开局 → 开场 3 秒先给"亮股权文件"的结果画面（正一钩子），再倒叙受辱过程，保住前 3 秒留存。
3. 结尾钩子 → 档案特写前加一句台词"查下去，你会后悔的——署名：你的父亲"，把负一钩子强度提到 4，强化危机与悬念。
4. 节奏 → 本集整体贴合"负一、零、负一、正一、负一"拉锯组合，情绪曲线合格，无需大改。

## 6. 说明

- 密度"达标"参考：爆款短剧单集（3–5分钟）通常 1–3 个爽点；该参考为经验值，非理论硬性标准，报告中标注为参考。
- 若用户提供多集，按集分别输出心电图与指标，再给全集汇总。
